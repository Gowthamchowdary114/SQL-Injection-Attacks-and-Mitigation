SQL Injection Detection and Mitigation Project
Test Results

1. Vulnerable Login - Valid Credentials
   Result: Successful login using the isolated test account.
   Status: PASS

2. Vulnerable Login - Malformed Username
   Result: SQLite OperationalError occurred when the username
   contained a single quote.
   Status: DEMONSTRATED

3. Invalid Password
   Result: Both vulnerable and parameterized baseline queries
   returned no matching user.
   Status: PASS

4. SQL UNION Demonstration
   Result: A standalone SQLite UNION query returned two rows
   containing three columns.
   Status: PASS - SQL OPERATION DEMONSTRATED

5. Parameterized Query Inspection
   Result: The secure application uses a parameter placeholder
   and passes the username separately.
   Status: VERIFIED IN SOURCE CODE

6. Password Hash Verification
   Result: Correct password returned True; incorrect password
   returned False.
   Status: PASS

7. Secure Login - Invalid Credentials
   Result: The application rejected the login without displaying
   a detailed database error.
   Status: PASS

8. Authentication Bypass
   Result: Automated tests demonstrated a controlled authentication
   bypass against the intentionally vulnerable query in the isolated
   test database. The secure query rejected the same bypass input.
   Status: VERIFIED IN AUTOMATED TESTS

9. UNION-Based SQL Injection Against Login
   Result: The standalone UNION operation was demonstrated, but
   injection through the login application was not demonstrated.
   Status: NOT VERIFIED
